# ぷち、ぽこ。

ブラウザで押す・なぞる・裏返す、立体のプッシュポップです。

24個の自由操作、4個の試し押し、光る突起を順番に追う「ひかりをおう」、2種類の合成音、音量・消音、キーボード操作に対応。
ログイン・外部素材配信サービスへの接続はありません。Three.js は MIT ライセンスで同梱しています。

## ブラウザで遊ぶ

https://tkzlab.github.io/push-pop/?play=light

スマートフォン・PCから遊べます。音は最初のタップ後に有効になります。

## ローカル起動

Macでは `あそぶ.command` をダブルクリックすると、空いているローカルポートで起動してブラウザが開きます。Python 3が必要です。10分後に自動停止します。

このディレクトリで次を実行し、http://127.0.0.1:8873 を開きます。

```sh
perl -e 'alarm shift; exec @ARGV' 600 python3 -m http.server 8873 --bind 127.0.0.1
```

確認用サーバーは10分で停止します。再度遊ぶ場合は同じコマンドで起動してください。
ファイルを直接開くとES Modulesの制約で動作しません。

## 操作

- タップ／クリック：突起を押す。押し込んだ突起はそのまま残る。
- 指／マウスを押したまま移動：連続して押す。
- 「うらがえす」：反対の面から押す。途中でも裏返せる。
- 「ためし押し」：4個の突起で変形と音を比べる。大きさを戻しても状態を保持。
- 「ひかりをおう」：光っている突起だけを順番に押す。1面24個を終えると裏返せます。時間制限はなく、何度でも面を進められます。
- Tabで突起へ移動し、矢印で選択、Space/Enterで押す。

URLに `?play=light` を付けると、最初から「ひかりをおう」で開きます。

実機の物理的な抵抗や触覚フィードバックは提供しません。WebGL 2とWeb Audio対応ブラウザを想定しています。
音が使えなくても操作は可能。立体描画に対応しない環境は案内を表示します。

## 検証

```sh
NODE_PATH="$(npm root -g)" BASE=http://127.0.0.1:8873 node work/check.cjs
NODE_PATH="$(npm root -g)" BASE=http://127.0.0.1:8873 node work/audio-check.cjs
```

PlaywrightとChromeを利用。検証スクリプト、画像、設計メモはgit管理外のwork/にあります。
`?qa` で開く場合のみ、読み取り専用の状態と画面座標を検証用に公開します。
